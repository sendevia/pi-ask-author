# 作答页与总览页排版

`src/view-question.ts`、`src/view-rows.ts`、`src/view-summary.ts`、`src/view-editor.ts` 组成排版层。

## 责任

- `view-rows.ts`：选项菜单行、顶部 Tab 栏、字符框架按钮组（`renderButtonGroup`）、固定高度内容区（`buildScrollBand`）、状态通知、分割线、帮助栏、推演占位页等共享行构建器。
- `view-question.ts`：题目页。按带序输出整页：预览区、Tab 栏、题目标题块（含可推演标记）、补充说明按钮组、选项菜单、底部操作按钮组、状态与帮助栏；负责预览区高度、预览内容缓存与预览区 / 按钮矩形 / 菜单项行范围的回传。
- `view-summary.ts`：提交总览页。按同一带序输出整页：答卷内容区、Tab 栏、标题与提示、状态通知、确认提交按钮、帮助栏；内容区末尾是整卷补充按钮，两者矩形回传组件供鼠标命中。
- `view-editor.ts`：补充说明编辑页。编辑目标标题、上下文、编辑框与页脚提示，并回传编辑框在整页中的位置。

## 边界

- 只读取组件传入的只读状态；滚动位移、预览观察值与预览区行范围通过返回值交回组件，由组件在输入路径写回。
- 不导入 `component.ts`；排版数值取自 `layout.ts`，文案取自 `texts.ts`，着色取自 `theme.ts`。
- 内容缓存以 `revision` 与视口尺寸为键，不缓存语义状态。

## 决策

- 作答页自顶向下固定带序：顶部分割线、内容预览区、Tab 栏、题目标题块、选项区、状态通知与快捷键、底部分割线。
- 提交总览页与作答页同构：顶部分割线、答卷总览内容区、Tab 栏、总览标题与提示、状态、快捷键、底部分割线；内容区同样占满剩余高度，长答卷按行分页。
- 整卷补充按钮排在全部题目条目之后，随答卷内容一起滚动；未填写时按钮文案自带打开方式，已填写时在按钮内展示正文。
- 提交页底部固定一个右对齐的确认提交按钮，唯一动作是提交；作答未完成时点击与回车同义，跳到第一道未完成的题目并在状态栏说明原因，帮助栏不再重复提交按键提示。
- 预览区高度等于终端行数减去除它以外各带的实测行数（标题折行、多行选项标签、状态与帮助折行均计入），下限 `previewMinHeight`；聚焦项无可预览内容时预览区留空行，选项区不位移。
- 预览区始终横跨整行；内容超出时末行让给滚动信息行，可视行数随之减一。
- 四个视图各自输出占满终端全高的整页（同时输出顶部分割线与底部分割线）；剩余行补在内容之后，帮助栏与底部分割线恒贴底。
- 作答页可用高度等于终端行数：作答界面是整屏覆盖层，不再为工具调用卡片预留行数。
- Tab 栏同时回传各标签的可点击列区间，按钮回传各自的矩形（行范围与列区间）、菜单项回传行范围，鼠标命中全部在这些回传值上判定，排版层不感知鼠标；总览页的整卷补充按钮只在滚入可视窗口时回传裁剪后的矩形。
- 补充说明按钮组在题目标题块与选项菜单之间，题目整体批注的按钮在上、当前聚焦选项专属批注的按钮紧随其后，两者紧邻成组。
- 选项菜单只含可见预设选项；题目补充说明入口与确认推进在选项菜单之后的底部操作按钮组里，整组贴右缘对齐，宽度不够时换行后逐行继续靠右。
- 按钮框用字符绘制：上缘 `┌ ─ ┐`、两侧 `│`、下缘 `┕ ━ ┙`，框线字符取自 `layout.ts` 的 `buttonFrame`。
- 按钮宽度贴着内容（内容行右侧补白对齐右边框），内容超出可用列宽时按列折行；同一行的按钮高度对齐，短按钮的内容区补空行。
