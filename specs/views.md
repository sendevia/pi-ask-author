# 作答页与总览页排版

`src/view-question.ts`、`src/view-rows.ts`、`src/view-summary.ts`、`src/view-editor.ts` 组成排版层。

## 责任

- `view-rows.ts`：选项菜单行、Tab 栏、四区域整页组装（`composePage`）、字符框架按钮组（`renderButtonGroup`）、固定高度内容区（`buildScrollBand`）、状态通知、区域分隔线、提示区、推演占位页等共享行构建器。
- `view-question.ts`：题目页。按四区域输出整页：题目标题区（Tab 栏与模式徽标题名）、内容区（题目内容区 + 补充预览区）、作答区（选项菜单与选项补充 / 题目补充 / 确认推进的动作按钮组）、提示区；负责内容区高度分配、预览内容缓存与内容区行范围 / 按钮矩形 / 菜单项行范围的回传。
- `view-summary.ts`：提交总览页。按同一四区域输出整页：题目标题区（只放 Tab 栏，尚有题目未完成时补一行提示，不写总览标题）、内容区（答卷正文 + 整卷补充区）、作答区（整卷补充与确认提交按钮）、提示区；两个按钮矩形回传组件供鼠标命中。
- `view-editor.ts`：补充说明编辑页。题目标题区为返回按钮加可折行面包屑，内容区为编辑目标上下文与编辑框，作答区留空，提示区为状态通知与按键帮助，并回传编辑框位置与返回按钮矩形。

## 边界

- 只读取组件传入的只读状态；滚动位移、预览观察值与内容区行范围通过返回值交回组件，由组件在输入路径写回。
- 不导入 `component.ts`；排版数值取自 `layout.ts`，文案取自 `texts.ts`，着色取自 `theme.ts`。
- 内容缓存以 `revision` 与视口尺寸为键，不缓存语义状态。

## 决策

- 四个页面统一自上而下分题目标题区、内容区、作答区、提示区，整页不画外框双横线，Tab 栏就是整页首行。
- 题目标题区不留左右边距：Tab 标签不带前后空格、标签之间固定隔两列，标题行、题干说明与返回按钮均从首列起排，右侧直接用满整宽。
- Tab 标签由完成度图标、题目类型短标记与题号/短标签组成（形如 `[单选] 第1题`）：单选与多选分别用 `[单选]` / `[多选]`，带显示条件的加 `[条件]`，本次会话提供推演服务且该题声明参与推演的加 `[推演]`；题名行只留题名与题干说明，不重复类型标记。
- 多选的最少与最多勾选数不在界面上常驻，由确认按钮的已选计数（仅题目显式声明 `minSelect` 或 `maxSelect` 时出现，形如 `确认本题 (1/2)`；上限优先，仅声明下限时显示下限）与状态栏提示承担，类型短标记只区分单选与多选。
- 内容区高度等于终端行数减去除它以外各区域的实测行数（标题折行、多行选项标签、状态与提示折行均计入），下限 `contentMinHeight`；聚焦项无可预览内容时题目内容区留空行，作答区不位移。
- 内容区与作答区之间不画分隔线，选项行直接接在内容区末行之后；标题区与内容区之间、作答区与提示区之间各保留一条单横分隔线。
- 题目内容区不带区块标题：选项设定说明与正文草稿直接按 Markdown 渲染，没有草稿也没有设定时显示「无内容预览」占位行。
- 补充预览区分行列出补充正文（作答页为题目补充与聚焦选项的补充，总览页为整卷补充），没有补充时整个子区连分隔线一起省略；子区至多占内容区一半高度，超出时末行换成指向编辑器查看全文的提示行。
- 整卷补充的正文也在补充区呈现，因此总览页的整卷补充按钮只保留入口文案与「已填写」标记，不在按钮框内嵌正文。
- 作答区没有可操作内容时（编辑页与推演占位页），整区连同其分隔线一起省略，内容区直接衔接提示区。
- 提示区自上而下是临时状态通知（有通知时才占行）与快捷键提示，均贴左缘悬挂缩进，超宽时折行。
- 作答区按钮整组靠右对齐：首列由剩余宽度自动推开，末按钮贴右缘；一行放不下时按字符框架规则换行，每行同样贴右缘。
- 内容区始终横跨整行；内容超出时末行让给滚动信息行，可视行数随之减一。
- 编辑页的返回按钮与面包屑同块排版：按钮在左、面包屑在右，首行与按钮内容行同行，超宽部分向下折行并对齐文字起始列；按钮旁可用列宽低于 `leadingTextMinWidth` 时改为按钮在上、面包屑在下堆叠。
- 四个视图各自输出占满终端全高的整页（不输出顶部与底部框架线）；内容区吸收剩余行，提示区恒贴底。
- 作答页可用高度等于终端行数：作答界面是整屏覆盖层，不再为工具调用卡片预留行数。
- Tab 栏同时回传各标签的可点击列区间，按钮回传各自的矩形（行范围与列区间）、菜单项回传行范围，鼠标命中全部在这些回传值上判定，排版层不感知鼠标。
- 作答页的选项补充、题目补充与确认推进归为一个动作按钮组，排在选项列表下方的空白行之后；总览页的整卷补充与确认提交同属一个组，两组都整组靠右。
- 选项菜单只含可见预设选项；按钮组靠右对齐，一行放不下时按按钮规则自动换行，换行后的每一行仍然贴右缘。
- 按钮宽度不预先写死：先用 `visibleWidth` 量出每个按钮的自然列宽（宽字符按 2 列、ANSI 不计宽），再决定分行与分配。
- 分行看「压缩后还能不能读」：一行内每个按钮最多压到自然宽度的 `buttonShareShrinkRatio` 能装下才同行，否则另起一行；因此长文字按钮与小按钮能并排，长文字在自己的框内折行。
- 行内列宽按自然宽度递进均分：窄按钮先拿足自然宽度，剩余的列宽全部给宽按钮并在其分配宽度内折行，短标签不会被平白拉宽。
- 按钮框用字符绘制：上缘 `┌ ─ ┐`、两侧 `│`、下缘 `┕ ━ ┙`，框线字符取自 `layout.ts` 的 `buttonFrame`。
- 内容行右侧按 `padToVisibleWidth` 补白至框内宽度，保证内容行与上下缘等宽；同一行的按钮高度对齐，短按钮的内容区补空行。
