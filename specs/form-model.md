# 问卷数据模型与状态机

`src/model.ts` 是问卷语义状态的唯一持有者，`AskAuthorFormModel` 是它的实现。

## 责任

- **归一化**：收敛题目与选项字段、补全默认值、校正 `minSelect` / `maxSelect` 与选项数量的关系；重复题目 ID 回退为顺序生成的 ID，再次冲突时追加序号后缀。
- **显隐快照**：解析并校验 `showIf`（只能引用更早题目、选项必须存在），按 `revision` 缓存可见题目、可见选项与可见选中项；隐藏项的选择与批注不参与作答判定与答卷。
- **作答状态**：单选替换、多选上下限、全选与清空、题目级补充说明、选项级批注（未勾选的选项同样可写）；整卷补充独立于各题状态，空文本视为清空。
- **推演记录**：`pushExpansion` 按生效的插入位置（题目级优先于表单级）把新题目插到触发题目之后、队尾或自定义锚点之后，把新选项追加到目标题目末尾；插入与 `retractFrom` 一起平移后续题目的条件、作答状态与记录索引，被撤回的题目连同其作答一并剪除；`answerSignature` 提供「同一答案不重复推演」的判据；题目总数上限在此截断。
- **答卷编译**：`compileAnswers` 产出 1-based 的答卷条目，显示中的题目即使跳过或只写批注也产出条目。
- **封套文本**：`formatAnswers` 生成面向模型的 Markdown 封套，插值文本先单行化并消解定界符，防止作者的文本提前闭合或伪造封套令牌；整卷补充作为作答行之后、收尾指令之前的独立令牌行输出，无补充时封套字节不变。

## 边界

- 依赖 `format` / `layout` / `schema` / `texts`；不引用 `Theme` 与任何 TUI 组件，版面全部上移组件层。
- 内部作答状态使用 0-based 索引，对外答卷使用 1-based 编号。
- 越界写入、非法条件与未知题目就地抛出，由入口层映射为结构化错误。

## 决策

- 构建期再做一次字段兜底，绕过 `sanitize.ts` 直接构造模型时同样安全。
- 封套中自动生成的占位标题与标签替换为英文（`Question N` / `Option N`），作者界面保留本地化占位；作者自己写的文本原样保留，不做翻译。
- 封套前缀与结构保持字节稳定，提高模型前缀缓存命中率。
